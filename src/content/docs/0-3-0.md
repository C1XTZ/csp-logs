# Changelog

## New Features, Options and Improvements

#### New Main Menu

*   Enabled by default;
*   Option to load last setup automatically;
*   Change spawn set in an offline practice mode;
*   A bit of extra details about selected car;
*   Chat settings are available, look of the new chat in the old menu is improved as well;
*   Telemetry and Lap Times buttons are available with all window sizes;
*   Infinite sessions are shown as such, duplicated weather row in session info removed;
*   Leaderboard uses custom driver icons, if set;
*   Race info: click on sessions on top to quickly switch between them (stepping back is not available online);
*   Time table: times from previous sessions, times for different cars, printing fixed;
*   If lap splits are empty, lap splits from the previous lap will be shown, matching original behavior, and split times are rounded the same way they are in the original menu;
*   Look for cooldown timer and such updated, sessions selector when viewing lap times and such fixed;
*   Drive button changes icon based on setup test status;
*   At the first button press, mouse moves onto the drive button;
*   Menu movement with a mouse updated, now a lot less restrictive, hold Ctrl to move components and avoid accidental shifts;
*   No longer ignores the mouse in compact mode when shifted up;
*   Ctrl+Tab in main menu goes through Telemetry tab too;
*   Hold Shift and click on car preview in the main menu to change color in a single-player session;
*   Car preview in setup menu: a bunch of fixes and shading improvements, LOD A is used at all times, driver model no longer flickers for a frame when leaving setup section;
*   Fog in car thumbnail fixed (also affects car shots);
*   Compatible with `FORCE_START` option, as well as with `ac.tryToStart()`;
*   Support for custom number of Quick Setup menu presets;
*   Margin for window titles fixed, crash in setup with some types of items fixed;

#### New Main Menu Setups
*   Better setup titles (let me know if I missed any abbreviations), if any setup tab title has a lower-case letter, CSP won't adjust case;
*   `Randomize setup name` button turned into a menu for extra functionality;
*   Press Enter to save setup when typing its name, clicking on saved setup brings its name into `Save setup` name input (but only if it's empty or has an autofilled name already);
*   Fix for saving setup (name editing, empty category selection by default, missing extension), setups without category are shown as well;
*   Other tracks are present in the list of setup categories even if `Skip creating setup folders` option is enabled;
*   Vertical setup tabs scroll to keep the selected tab in view, mouse wheel scrolling setup tabs is optional (disabled by default);
*   Hidden tabs can no longer be selected, tab reset works for more types of tabs;
*   Support for setup items sharing the same place with only one visible and others hidden, `EXT_VISIBLE_WITH` works from the start, not waiting for something to change;
*   Look and behavior of disabled setup items improved, better support for specific setup items, better positioning;
*   Heuristic for detecting mirrored setup items updated, checks display multiplier and setup item labels;
*   Extra setup items in tyres section use full logic for different types, max tyre temperatures are shown properly;
*   Fixes for setup items missing their default value and other details (often affected items in Alignment), sliders malfunctioning on items with `%` units and cars with 0 for a gear ratio;

#### New Pause Menu

*   Can be moved as well (drag it with a mouse to adjust its vertical position), photo mode button animations adjusted;
*   Always behind other windows, with an option to show apps in pause menu, photo mode in pause menu hides pause menu apps;
*   Compatible with mouse steering with apps in pause menu enabled;

#### New Taskbar

*   An option to change the edge of the screen the taskbar is on;
*   An option to configure icon alignment;
*   Blurs things behind it;

#### Hotlap Rework and Multiple Ghosts

*   Ghost is saved for all laps (only 5 best and 5 last laps are kept);
*   Ghost includes car setup, performance meter data, best lap time, comparable telemetry data, conditions details and more;
*   Manage and choose between ghost records from the main menu, show and load ghosts of other cars;
*   Load best lap time, performance meter and such from ghost, or just keep them across restarts (everything is optional);
*   Load weather and other conditions to match a ghost record, quickly set starting or ideal conditions;
*   Filter ghosts based on tyres and car (now, you can load a ghost for a different car too);
*   Option `Use original materials` loads the skin as well;
*   Ghost advantage can be edited live, ghost playback and recording can be toggled live;
*   Loaded best lap time shouldn't show up in shared memory or in race output;
*   Ghost recording stops on messed up laps, or if the car is in pits or stationary for a bit too long;
*   Laps done with AI (with AI lap invalidation disabled using the new option) are marked;
*   Ghost of the first lap is recorded correctly;
*   The best ghost is mirrored to where AC stored ghosts originally (including layout ID), with extra data stripped, so that existing tools could still see the ghost (optional, enabled by default);
*   Support for `LOAD=0` and `FILE=explicit-filename.ghost` in ghost configuration in `race.ini`;
*   Most of these things won't be available with RSR app present, to be safe (akin to other physical experiments);

#### Built-In Lap Time App

*   Before crossing starting line for the first time, current lap is shown as 0;
*   Extrapolation for current lap time to show the time precisely at the time the frame is being drawn;
*   Time transponder operates with 1 ms precision (physics experiment);
*   Another physics experiment to start the first lap when crossing the starting line for the first time in practice sessions with hotlap start;
*   New non-physics experiment for recording ghost with 1 ms precision;
*   New non-physics experiment changing number of samples of performance meter based on track length (enabled by default);

#### New Modes

*   New Revenant mode: a custom ghost with all the visual effects and proper collisions, hold bound button when recording to restart recording;
*   Revenant mode has since been pretty much rewritten from scratch by Neoned:
*   Alt-tab drift compensator: replaced per-tick threshold with a running-balance accumulator, persists across recording, idle, and playback phases;
*   Mid-playback alt-tab no longer truncates the ghost;
*   Ghost resumes at the exact paused frame after exiting AC's built-in replay (was teleporting to recording start);
*   Fixed `Recording lost due to rewind` after replay-exit cycle;
*   Added replay-exit grace window for car teleports and a post-replay settle window for the compensator to filter AC's transient session-clock snaps;
*   KO threshold in breakable mode now uses horizontal magnitude of relative velocity, kerb-bounce vertical spikes can no longer false-trigger KOs;
*   Removed directional bias on angled contacts, clipping the rear corner now KOs at the same closing speed as a head-on hit;
*   Traffic mode: options can be edited in-game, cars spawn more lively at the start;
*   P2P 1v1 and other `altonline` modes: sound from other cars (as well as from cars initially loaded as `nul`) fixed, flags in car state are applied correctly, no longer fails to load on some PCs;
*   New `[CUSTOM_PHYSICS] DISABLE_ANY_EXTRAPOLATION=1` for exceptional cases (pretty much only for `altonline` to do its own extrapolation);

#### Settings Regrouped, Some Removed, Others Changed

*   Lights FX, Fake Shadows FX, GUI, Reflections FX, Track Adjustments and Smart Mirrors modules can't be disabled anymore;
*   Colored shadows can't be disabled, entire settings section hidden;
*   Wheels-related visual things merged into a single config (only change that might cause some user settings to be lost);
*   Distant headlights glare is enabled by default;
*   Default chunks optimization switched to advanced (with a lot of fixes and improvements);
*   Option forcing render route with FXAA is active and hidden;
*   DPI-aware option is active and hidden;
*   New KN5 loader is always active, physics meshes data stripping enabled by default;
*   Some other extra settings are hidden;

#### New Window Creation and Handling

*   Exclusive fullscreen has been replaced with a modern compatible fullscreen implementation (just in case, old approach is available as an option);
*   Flip model is active everywhere, including VR, unless compatibility option is used;
*   Alt+Enter is more reliable, with AC keeping its windowed size across sessions, maximize button works the same as Alt+Enter, binding for Alt+Enter can be changed;
*   Pressing Alt+Enter if AC window covers most of two monitors will extend it to cover those two (or more) monitors;
*   Toggling fullscreen works better when aspect ratio of configured resolution doesn't match monitor aspect ratio;
*   Borderless window option (it can still be dragged and resized, even without a visible frame);
*   Option (disabled by default) to keep AC running when the window is being resized, `Smooth resize` option is enabled by default and improved a bit;
*   Cursor clipping (previously used for VR) reworked, now can be activated for windowed mode without VR too;
*   Options confining cursor to AC window, forcing AC to be a topmost window and forcing focus that can be enabled based on conditions (fullscreen and/or VR, or always);
*   CSP UI ignores mouse if the window is not actually foreground (affects UI and visual stuff; any physics or audio components still using old way of checking covered percentage of the screen to be extra safe);
*   Mouse cursor no longer hides if it's hovering an IMGUI window;

#### DXGI Tweaks

*   During DirectX initialization, CSP keeps track of whatever is going on and shows the culprit in possible slow downs (without that annoying popup message about initialization being slow);
*   Render scale adjustment is done by CSP now, should resolve some potential issues with variable rate shading and looks better too (quality can be adjusted in Graphics Adjustments);
*   Compatibility with variable refresh rate improved, no longer optional, enabled by default to make sure people don't experience unexpected performance regressions;
*   V-sync video option works with the new swap chain, with alternative V-sync implementations in case Windows 11 with its `Variable refresh rate` option blocks regular V-sync from working;
*   New `Adaptive V-sync` option temporarily pausing V-sync if FPS dips below 90% of display refresh rate, to prevent FPS halving (disabled by default);
*   New experimental `Account for forced V-sync` tweak for those who activate forced V-sync in GPU drivers;
*   New option `Pace frames better` (disabled by default) helps to reduce latency by asking GPU to time when to start rendering the next frame;
*   Frame limiter reworked, now hits target FPS precisely;
*   Frame limiter in VR is disabled entirely, unless re-enabled in VR Tweaks (it really should be up to the runtime to time the frames);
*   When GPU asks to slow down (for example, when screen is off), AC will listen;
*   New tweak activating Win11 efficiency mode when AC is in background, enabled by default;
*   New `Consider DXGI's occluded state` tweak (can be disabled to debug issues if AC suddenly stops rendering sometimes);
*   New experimental background idle option pausing rendering instead of limiting FPS (might help with some glitches on certain systems where AC would sometimes refuse to wake up after being Alt+Tab'ed back into);
*   Option to select brand of target GPU in DXGI Tweaks settings;
*   HDR rendering is compatible with YEBIS replacement;
*   If HDR is enabled, but not available, config loaded with `ac.INIConfig.cspModule(ac.CSPModuleID.DXGITweaks)` will have that option disabled;
*   Shaders cache purging on CSP updates no longer clears out cache of other games, and is disabled by default (re-enable it if your initialization times become too long);

*   Controller visualization (render controllers as points and a blue line) updated;

*   Mumble integration: headsets orientations are taken into account;
*   Ctrl+…+F10/F12 reports include VR screenshots as well;

#### Variable Rate Shading for VR

*   SPS is no longer required, settings moved to a separate section (to keep old presets working, SPS settings will be reset instead);
*   Areas automatically align with view direction;
*   In case automatic alignment fails, options to tweak things are available, with an optional debug overlay too;
*   Outer VRS radius is ignored completely, so rendering no longer stops in outer regions after the `Align with eyes` option;
*   Custom VRS rate and area are configurable;
*   New VRS supersampling option;
*   VRS quality: different quality options for Quest 3 presets;
*   VRS no longer applies to HUD;

#### Upscalers

*   FSR settings are reworked into upscale settings (presets remain compatible);
*   FSR updated to 1.0.2, new simple methods: NVIDIA Image Scaling, Snapdragon GSR, Basic;
*   New pixel density upscalers: Snapdragon GSR1 (so good and fast it's enabled by default, compatible with HDR output), `Catmull-Rom` (looks similar to Lanczos but faster, also added as a variant to Basic upscaler), `Point` for a test;
*   New advanced Extra FX-based upscalers: FSR2, FSR3, FSR3/4 using DirectX 12 API, DLSS, XeSS 3.0.2 (works with GPUs other than Intel Arc), SGSR2 and OptiScaler;
*   DLSS updated to 310.9.16, better support for user-provided DLLs, CSP checks custom DLSS DLLs for integrity unless disabled, to keep users safe (list of known unofficial DLLs extended);
*   New (old) DLSS presets, E and F, might help with ghosting;
*   Temporal upscalers (DLSS, FSR2, XeSS): option for foveated upscaling (using SGSR2 for the outer regions);
*   FSR 2/3: reactive mask improved for the image to be a bit less jittery around wheels, FSR 3 is loading on-demand;
*   OptiScaler updated to 0.9.2, with working in-game menu, working on AMD GPUs, not interfering with in-game browser, loader tries to migrate settings from the previous version;
*   DLSS, XeSS and SGSR2: option to use FFX CAS for sharpening instead of NIS;
*   Advanced upscalers are working in triple screen mode, with and without lower quality for sides, temporal upscaling is working with triple module disabled, or with `fit resized splits properly` disabled;
*   Advanced upscalers: MIP bias is fixed, always disabled for accumulation screenshots, compatibility with curved monitor filter improved, virtual mirror is forced to be drawn last;
*   Option to adjust YEBIS glare to compensate for the lower scale and prevent excessive flickering, glare slider in View & Video settings goes all the way to 7 (highest quality);
*   Fallback mechanism doesn't use NVIDIA Image Scaling if quality is above 100% (it can't handle that);
*   Some upscalers in some configurations are a bit faster, no longer performing unnecessary copying step;
*   Enabling upscaling hides sharpening settings from post-processing antialiasing section;
*   Sun shadow ghosting with upscalers or TAA should be reduced a bit;
*   Windscreen reflections won't work with DLSS and such, unless explicitly enabled (not recommended; maybe eventually I'll figure out a good way to get it to work, but this kind of effect goes against the whole nature of temporal upscalers);
*   New driver tags are compatible with DLSS and other advanced upscalers;
*   Basic upscaler: new `motion test` mode to debug advanced upscalers;
*   `Disable for screenshots` option works, custom FSR scale shouldn't lead to a crash anymore, crashes with misconfigured video settings (there is never a need to set MIP LOD bias below -5) fixed;
*   Disabling Extra FX live no longer messes up rendering, `dynamic::screen` Lua texture no longer includes flicker;

#### Neural Rendering

*   Option to enable Neural Rendering (needs the library for it to work);
*   Works without upscalers, compatible with HDR output;
*   Settings moved to a separate section (use in-game app to move NR before upscalers);
*   Preset option (working with the new DLL);
*   Foveated rendering (reduce NR resolution towards the edges);
*   Visual tweaks in in-game app, including multiple passes, extended boundaries and a `loop` slider in `Go beyond` settings, enabling the effect mid-session adds the tweaking app;
*   Accumulation screenshots improved, now NR applies once at the end instead (optional, enabled by default, can be changed in screenshots settings);
*   Small Tweaks: option to apply Neural Rendering to CSP car previews;
*   Slider for passes without upscaling shows the actual value when loading into a new session after disabling upscaling, error message related to GPU overclocking is a bit more informative;
*   Crashes when resizing AC fixed;

#### Extra FX and TAA

*   TAA rewritten from scratch: better sharpness, less ghosting, better antialiasing, compatible with trees wind animation, adjusted to be a bit less flickery, especially around flags;
*   TAA works with custom rendering modes and custom triple cameras override;
*   Motion blur shader updated to improve visuals and address a few issues, blurred regions blend slightly better, blur doesn't leak color from side to side with custom rendering modes;
*   Motion blur and TAA no longer freak out on window resizes, motion buffer fixed for single and triple screen modes;
*   Look of some windscreen banners with Extra FX TAA fixed, rendering of MX-5 dashboard needles with DLSS (or TAA) fixed;
*   Fix for a typo in preparation process causing a bunch of effects to malfunction, an old bug with bounced light in triple has been fixed as well;
*   Ideal line no longer illuminates everything with Extra FX;
*   Long speculars of SSLR are compatible with LCS;

#### Custom Rendering Modes (Splitscreen, 360°, Fisheye)

*   Mouse rays (used for pretty much any mouse-scene interaction) are working correctly;
*   A compatibility issue with upscalers, 360°/fisheye and sharpening in AA settings fixed;
*   `dynamic::screen` Lua texture is working properly;
*   Splitscreen:
    *   Stability control and other AI tweaks no longer apply to the second car, input smoothing for second car is disabled;
    *   System shortcuts changing ABS, TC and such apply to both cars at once;
    *   Grass FX is properly shown in the second view, second view also got its own reflection cubemap, discrepancy in headlights intensity fixed;

#### OBS Views and Geometry Shots

*   New `Higher quality` option with dedicated grass spawn and shadows set;
*   `ac.GeometryShot:update()` got an overload accepting actual view and projection matrices, as well as options for dedicated grass spawn and shadow maps;
*   Geometry shots: grass is drawn before particles;

#### Smart Shadows

*   Adaptive first split rewritten, active for bonnet and dash cameras, making shadows sharp with F1 cars (but disabled with other drivable cameras, making shadows extend further with chase and bumper cameras);
*   First split reduction when camera is close to a car adjusted, should work smoother and have a more pronounced effect, also affects other splits;
*   Custom matrices and automatic distances adjusted to reduce jitter and increase quality;
*   Shadow biases adjusted to reduce self-shadowing issues with double-sided shadows;
*   When the sun is low, sun shadows trajectories update every frame (shadows moving unsmoothly look like crap, so I'm ok with a bit of a performance hit in exchange for that lovely smoothness), shadows move smoother in general;
*   Shadows flicker around cars in medium distance (noticeable on a race on Nordschleife when starting last, for example) fixed;
*   Shadows with custom shadow matrices disabled no longer break if origin shift is enabled;
*   Shadows on grass are slightly adjusted to be sharper and more reasonable, trees receiving shadows adjusted;
*   Dynamic shadows: car headlight edges are fixed, other small improvements;
*   Double-sided track shadows option is disabled and hidden (it wasn't really needed and was breaking some good tracks);
*   Fake car shadows are better positioned for cars with only three wheels, with one wheel in the front, frustum culling adjusted, fake wheel shadows are better compatible with surface noise;
*   Surface noise upgrade fixed, scale adjusted (even previous Perlin was a bit too high, and newly added simplex was really wild);

#### CSP Trees

*   A few major bugs causing horrible performance issues fixed, few extra optimizations;
*   Optional depth prepass that might help with performance (disabled by default);
*   New `Better shadows for CSP trees` option using 3D models for shadows of trees nearby (for now, disabled by default);
*   Shading with LCS fixed, trees are no longer two and a half times brighter than they should have been, shading of trees without LCS fixed;
*   Small improvements to trees billboards, trunk width value used for billboards fixed, billboards of wide trees are drawn correctly;
*   Trees in mirrors can receive per-vertex shadows (without using most expensive mirrors option) and react to wind;
*   New `[LEAVES] COLOR_WEIGHTS` parameter to tweak automatic mask (multipliers for R and B, defaults are 0.9 and 1, for yellow leaves, use 0.6, 1.5, or just use `SEASON_AUTUMN_…` parameter when configuring the trees);
*   New `[LEAVES] LEAVES_ARE_NOT_BARK` parameter for trees: set it to 1, and all the meshes that are not explicitly bark will be treated as leaves (careful if your leaves textures include sticks and such);

#### Cables (On Configured Tracks, Such as Laguna Seca)

*   Anti-aliasing improved, now cables are actually a pixel wide, with better fading, better supporting different meshes;
*   Wind animation fixed, cables are slogging a bit based on ambient temperature;
*   Option for track configs to make cables transparent and use alpha-blending instead of previous color (enabled by default);

#### Visuals

*   Interior masking works a lot better with LCS;
*   VAO applies to refracting headlights, `fuPBR` shaders use VAO properly;
*   Flickering reflections (happening sometimes with a single face per frame and reprojection with LCS) fixed, reflections reprojection is smoother, especially for rougher surfaces;
*   Light bouncing off cars fixed, light bouncing off track surface shouldn't illuminate car interiors anymore;
*   Bounce-back effect takes environment brightness into account as well, just a bit, for more lively look;
*   A bit of shine for grass at grazing angles with LCS;
*   Puddles got waves if wind is strong enough;
*   Windscreen shaders flip normals in pixel stage if they detect surfaces facing away from camera (for example, fixes Porsche 911 Carrera S);
*   Inverse side of tyres (which started to be drawn around 0.2.6) got an offset, so if a car has tyre meshes double-sided to begin with (for example, Lamborghini Diablo SV by slang_diablo_sv), it wouldn't look wonky anymore (offset is 2 cm);
*   CSP tyre skidmarks no longer have speculars (doesn't affect ice, dirt or gravel marks);
*   Tyres FX damage normals and shading fixed;
*   Brake Disc FX: glow is applied to a mesh in LOD B, if any, as well;
*   Brake sparks disabled entirely until I'll find a better way of tuning it;
*   Depth-based particles collision fixed, now sparks and pieces can be present under bridges;
*   Rear mirrors use clamping sampler, fixing occasional rendering artifacts, fake shadows and other things missing in mirrors fixed;
*   Virtual mirror without post-processing looks a bit more sane, trying to mimic YEBIS HDR→LDR step, that simplified YEBIS step (used for virtual mirrors with some upscalers, for example) syncs with autoexposure and supports all built-in tonemap functions;
*   Reflections FX: new experimental option to position reflection cubemap at the ground (experimental & broking things);
*   If there is not enough memory for local cubemaps, they'll be skipped instead of crashing the game;
*   A few improvements to the shape and shading of fallback LOD;
*   Neck FX: helmet rendering fixed, helmet definitions for `rh_bell_dply_type4` added;
*   Windscreen reflections no longer crash the game when swapping cars in some cases;

#### Content Shaders

*   Shaders clamp output color to make sure it's never negative, so even wildly misconfigured materials won't break rendering too much;
*   `nePBR` shaders can handle clear coat F0 above 100% a bit better (F0 should never exceed 100%), shaders better handle `extColoredReflection` above 100%;
*   `smCarPaint` shaders: old flakes are a bit more pronounced with LCS;
*   New car paint flakes updated: defaults improved, new `FlakesMask` parameter, by default apply only if original materials were doing flakes as well;
*   `fuPBR_multilayer` shaders are no longer pixelated at 10+ km from center of the scene;

#### Default Weather FX Style

*   Clouds rewritten to have more depth and better performance, extra cloud layer appearing occasionally fixed;
*   Cloud shadows are nice and sharp;
*   New `Volumetric fog` effect (experimental, disabled by default): cooperates with rain haze, fades out when sun is low and shuts off sooner during sunsets, replaces fog backlighting entirely, with some denoise both temporal and regular, smoother with TAA, works better with super-low FOV views;
*   Fog is a bit less bluish, fog backlighting is dimmed in tunnels, sun shadow altering fog backlit is smoothed to prevent flickering;
*   Brightness adjusted, white reference point accounts for post-processing exposure, ensuring the same brightness in different conditions (LCS only);
*   Bloom intensity depends on weather clarity;
*   Ambient shadows are a bit less dark, some of the more extreme weathers are tuned to be less extreme;
*   Some small adjustments for grass shading and fog hues;
*   Sun rays are tuned down, especially in VR, lens glare in VR disabled entirely;
*   Sun rays of YEBIS replacement are improved a bit;
*   Lightning is brighter, stays around a bit longer and illuminates the scene more;
*   Auroras fixed (there was this annoying shifting of pixels), list updated;
*   Rain audio fixed, boosted for higher intensities and adjusted, puddles audio is working with rain and wetness at zero;
*   Slow cubemap update is twice as fast, using `ac.setReflectedSkyTweaks()` no longer activates that option (in full);
*   Outer space shading adjusted, Earth textures and shading updated, thanks to Artemis 2 mission, with a few fixes for Extra FX as well, hi-res Earth textures are loaded on demand;
*   Eclipses are visible from space, lighting with full eclipse fixed, full eclipse projection fixed, stars are brighter, with a bit of gravitational lensing during a full eclipse event;
*   Refraction of sun close to horizon fixed (it was working in space instead of working everywhere but the space), atmospheric refraction is taken into account when drawing stars;
*   YEBIS replacement: enabled HDR stops it from dithering and clamping the output, NaN protection added;
*   YEBIS replacement: if a scriptable filter requires for virtual mirror post-processing to be done separately, it can handle the request and add a bit of glare too, glare in the virtual mirror is reduced, virtual mirrors not getting proper post-processing applied in some cases fixed;
*   Using simplified YEBIS post-processing on 1×1 textures no longer leads to a crash, small fixes for resizing geometry shots with YEBIS post-processing;
*   Weather FX styles accessing output buffer with post-processing disabled shouldn't crash anymore;

#### Rain FX

*   Rain physics tuned, should be manageable now, rain physics malfunctioning on some tracks with certain configurations fixed, ideal line messing up rain physics on some tracks fixed;
*   New `[RAIN_FX] IDEAL_LINE_RAIN_FACTOR` for track configs (set to 0 to stop rain physics from taking ideal line and its corresponding rubbering into account);
*   Rain drops are more compatible with TAA, more intense for heavier rain, more rain hits for overly intense rains, amounts of rain drops and windscreen drops adjusted, a few small tweaks for visuals;
*   Rain hits and splashes are slightly readjusted to reduce aliasing and better react to rain conditions, rain hits fade nearby to be less distracting with open wheelers, thresholds for splash particles adjusted;
*   Rain splashes adjusted to fix issues with brightness, especially with LCS, now with a bit of a rainbow on a sunny day;
*   Rain on glossy surfaces (such as car paint) adjusted, shading improved;

#### KN5 Streaming (Experimental, Requires to Be Configured in Track Config)

*   During first loading, CSP computes final mesh vertex data and materials, and then stores them in cache (per-layout or per-KN5 depending on config), in subsequent sessions, it loads nearby meshes live and unloads them when they're far enough;
*   The whole mechanism is an extension of advanced chunkenization, materials (without textures) are initialized at the start, so it's better to still use limited number of materials;
*   With low FOV, streaming switches to a different map with distance radii tripled, with even lower FOV, to a map with distances multiplied by 30;
*   Supported: shader replacements and material adjustments targetting materials, model replacements, streamed physics meshes, Grass FX, bounced track light, track map, dynamic shadows, local heightmap, Rain FX, heating surfaces, sun shadows physics experiment, baked mesh optimizations;
*   Any piece of logic referring to specific meshes (such as spawning lights based on geometry, or distant emissives) won't be compatible, and live config changes aren't meant to apply to streamed geometry;
*   Configured with `[KN5_STREAMING_…]` sections: `FILES` (list of KN5s to stream), `MESHES` (filter), `LAYOUT_SPECIFIC` (per-layout cache file, for meshes depending on per-layout VAO), `INCLUDE_PHYSICS_MESHES` (physics counterpart still loads instantly, as a non-renderable mesh);
*   Fix for missing textures with KN5 track asset streaming;

*   New `shared/utils/luasteam` for full access to Steam API available to all scripts with I/O access (forked version of `luasteam` with a few more functions and a bunch of small fixes), `screenshots` and `music` modules fixed, no longer tries to load the GNS DLL for no good reason;
*   New `shared/utils/parcel` for exchanging small bits of data, new `shared/utils/openkneeboard` library for sending commands to OpenKneeboard, new `shared/utils/steamvr` library for some Steam VR extras, new `shared/vr/vrmisc` library reporting raw device position for debugging (`.rawDeviceTransform()`);
*   New `shared/utils/oswindow` library for creating extra OS windows, with `.monitors()` returning list of available monitors;
*   New `require('shared/utils/osutils').isHDREnabled()` to check if HDR is enabled in Windows settings;
*   New `shared/utils/playing` functions to control playback in detail, such as `.seek()` or `.setShuffle()`, `.spectrum()`, `.fftMagnitudes()` and `.fftRawData()` (rely on new music monitoring options), `ac.mediaPlayPause()` and other two use direct media control if available;
*   New `shared/sim/plates` for generating license plates in Kunos style (currently, requires I/O access and uses assets from Content Manager);
*   New `shared/sim/di` library for altering some properties of `digital_instruments.ini` live;
*   New `shared/sim/events` library for rare events (currently, allows Weather FX styles to listen to light pollution configuration changes);
*   New `require('shared/sim/cars').getTyreType()` to get the type of a tyres set, new `require('shared/sim/cspdebug').hideCarInReplay()` function for scripts with I/O access;
*   `shared/sim/surfaces`: new `surfaces.raycastDetailed()` (got a `surface.originFilename` field, arguments to skip walls, or everything but walls, and for backface culling), new `ac.SurfaceExtendedType.Wall`, fix for `surfaces.propertyAccessor()`;
*   `shared/sim/weather`: new `.rainMmPerHourToIntensity()` and `.rainIntensityToMmPerHour()` (rain intensity will be reworked next though, so do not rely on this one), `.estimateRainIntensity()`: adjusted values for drizzle;
*   `shared/sim/ghost` got a lot more new stuff, overriding ghost time and such is more reliable, new `ghost.stripRecordMetadata()` for getting rid of extra 0.3.0+ ghost data;
*   `shared/utils/signing`: new `signing.check()`, new `{CSPVersion}`, `{CSPVersionCode}` and `{UniqueMachineKeyBase64Trimmed}` for signing format string, queries to quickly and easily verify integrity of cars and tracks, as well as AC's `surfaces.ini`, `verify` function can handle absolute paths, other fixes;
*   New functions for `shared/utils/ioext`, `shared/sim/fireworks` library is more responsive, `shared/sim/altonline`: a couple of fixes for documentation;
*   GameNetworkingSockets: if signalling service is not configured, the default one will be used instead;
