# Changelog

## New features, options and improvements

*   Purging the shaders cache on CSP updates is disabled by default, re-enable it if your initialization times become too long;
*   A regression with some of `nePBR` shaders fixed;
*   `Cars extrapolation` option is back until I figure it out properly, and is now available online as well (it's purely visual);
*   Amount of rain on the windscreen adjusted, properly taking car speed and wind velocity into account;
*   Water splashes are more likely to spawn drops on windscreens, now make the cars wet as well;
*   Marbles particle system is back, now with optional saving between sessions (for now, disabled by default);
*   Custom physics: cars with turbos no longer get faster with warmer ambient air (recent regression);
*   Rain effects fade out smoothly, instead of instantly terminating the moment all the rain values are set to 0;
*   Small fixes for rain racing line misbehaving in some cases;
*   Mumble integration: headsets orientations are taken into account;
*   Online servers can add `[PHYSICS_EXPERIMENTS] ISOLATE_CARS=1 WHEEL_CAR_CONTACTS=1` for the new collisions;
*   A new per-car flag allowing to change tyres per axis online;
*   Smoke: a few improvements to movement (better smoke-vs-car collisions, ditched random shuffle misplacing particles, a better tweak for locked wheels);
*   The way CSP checks whether the track mesh can be altered during loading has been fixed to match original logic and to respect `[_EXTENSION] ALTERNATIVE_PHYSICS_MESH_DETECTION=1` tweak;
*   Light sources for starting lights no longer duplicate;
*   New experimental `Account for forced V-sync` tweak for those who activate forced V-sync in GPU drivers;
*   Smart Shadows: custom matrices and automatic distances adjusted to reduce jitter and increase quality;
*   VR tweaks: new `Sync pace with display` option that might help with jitter a bit;
*   OpenVR: OpenComposite detection improved;
*   Loading details with OpenVR won't be shown with OpenComposite or other DLL replacements;
*   OpenXR: vertical axis of gaze tracking inverted, `submit depth` is disabled without post-processing, should fix the problem with those configurations;
*   `Extrapolate state` is optional again, albeit improved;
*   `fuPBR` shaders use VAO properly;
*   Sun shadow ghosting with upscalers or TAA should be reduced a bit;
*   New (old) DLSS presets, E and F, might help with ghosting;
*   Ctrl+…+F10/F12 reports include VR screenshots as well;
*   Surface audio reworked for smoother transitions;
*   Disabled with distance audio events are stopping smoother;
*   Rim contacts are no longer delayed by a frame;
*   Improved compatibility with driver models without necks (previously, rain, VR, Neck FX and other modules could crash);
*   Driver models with other missing rig nodes shouldn't crash the game as well;
*   Cockpit camera (without Neck FX module) follows glance buttons or `__EXT_LOOK_AXIS` if TrackIR is inactive;
*   Crashes with postponed Lua online events should be fixed;
*   Original INI parser doesn't crash with malformed numerical values in regular configs; for cars and tracks, crash messages point to the faulty values instead;
*   Improved compatibility with Wine;
*   The AI-related crash with unusual AI splines fixed;
*   Fading out when the race is finished has been fixed;
*   Cooldown lap: chequered flag is working, option to limit the time (set it to something like half a minute to get a bit of a cooldown period after finishing a race, without having to do the whole lap), session actually finishes after a lap, AIs actually go to the pits;
*   New `Show chequered flag when leader finishes` option;
*   Multiple config files changing at once at runtime are handled better;
*   Generating compressed missing MIPs should work more reliably, especially the caching part;
*   New vintage DDS loader is disabled by default;
*   If Assetto Corsa fails to resize, it'll try again (might help with some third-party extensions);
*   Neural Rendering: slider for passes without upscaling is fixed, showing the actual value when loading into a new session after disabling upscaling, error message related to GPU overclocking is a bit more informative;
*   Opening weird files as replays is reported properly;
*   Custom binding for voting `Yes` fixed;
*   Track cameras: placeholder (shown with `OFFICE_PLACEHOLDER=1`) updated;
*   `ac.shiftPatchTemperatures()`: new argument for inner, middle and outer mask;
*   `ac.allowCarDRS()`: argument renamed to accurately reflect its behavior (there is a bug there, this is kind of a solution that keeps things compatible);
*   New `ac.StateSim` fields: `.headsetPosition`, `.headsetLook`, `.headsetUp`, `.headsetSide`;
*   New `physics.Collider.TrackWalls()` and `physics.Collider.TrackGround()`;
*   `io.scanZip()` no longer crashes AC if ZIP data is damaged;
*   `ui.endToolWindow()` fixed, shouldn't lead to crashes;
*   `ui.renderTexture()` is compatible with scrolling;
*   Small fixes for resizing geometry shots with YEBIS post-processing;
*   Dynamic track grooves (the basic fading-in grooves meshes) are working better with dynamic track state disabled;
*   If there is not enough memory for local cubemaps, they'll be skipped instead of crashing the game;
*   Track collider params using curves are treating friction and intensity correctly;
*   Dragging of core HUD components (damage and Quick Pits menu) should work better;
*   Flag meshes processing fixed, properly taking normals into account, and no longer stopping everything when getting to a mesh that ignores wind;
*   Python: `ext_getCarLightsMirrorVisible` and `ext_getTrackLightsMirrorVisible` fixed, now return correct values;
*   Python: `ext_getSuspensionTravel` respects corner argument for regular suspensions;
*   Accessing data after calling `ui.ExtraCanvasData:compress()` should work properly now;
*   Remote wheel offsets for the fourth wheel (`[_EXTENSION] REMOTE_OFFSET_RR`) work as well;
*   `[LIGHTS_DISTANT_LAYER] MESHES_…` values are read properly, `LAYER=31` is working;
*   Neck FX helmets: `DRAW_CULLED=0` is compatible with `APPLY_ALPHA_FIX=1`;
*   Xbox impulse triggers are paused when the race is paused;
*   A few smaller fixes;
