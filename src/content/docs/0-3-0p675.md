# Changelog

## New features, options and improvements

*   Frame limiter in VR is disabled entirely, unless re-enabled in VR Tweaks (it really should be up to the runtime to time the frames);
*   Scraping audio glitch (recent regression) fixed;
*   Alternative tyre model SFP updated;
*   `Adaptive AI` replaced with a different experimental tweak, also adaptive, but a bit more useful;
*   Scraping gravel with the bottom of the car, or grass and sand in general, now produces surface sound instead of scrape sound;
*   NVIDIA 3D Vision is once again compatible with the way CSP draws text;
*   AIs no longer fail to start with alternative throttle models (a bug caused by physical AI gas smoothing added a few months ago);
*   Internal materials binding logic rewritten to increase stability and improve performance;
*   FW1 fonts: optimized memory usage, improved performance and memory consumption;
*   Rain drops show up on tyres;
*   CSP cars audio: smooth level-of-detail changes, cars with labels hidden (usually traffic) are marked as lower priority;
*   Extended replay data loads from replays above 2 GB;
*   CSP Debug: option to show tyre temperature (on tyres);
*   Marbles particle system updated and improved, now enabled by default unless Marbles app is installed;
*   YouTube playback in Android Auto fixed;
*   Tyre smoke showing up in car interiors with accurate mirror projection fixed;
*   Mumble: sounds for direct PTT mode and orientation in VR are fixed, properly this time;
*   Custom motion online shouldn't misbehave for distant cars anymore;
*   Stuck FFB no longer leads to physics freeze crash and is shown as such instead;
*   A couple of mistakes leading to increased memory consumption in some cases fixed;
*   AC crashes due to damaged car colliders are shown as such;
*   Occasional crash caused by disabled heat shimmer fixed;
*   Broken car models no longer crash AC on loading when pit crew is being created;
*   Exhaust flashes in replays fixed;
*   New `Automatic` shader cache purging mode, kicking in if DirectX initialization is taking longer than 8 seconds;
*   Neck FX: helmet rendering fixed, helmet definitions for `rh_bell_dply_type4` added;
*   Default Weather FX style: rain audio adjusted;
*   Audio app: saving bumper audio level is fixed;
*   Empty track camera sets no longer crash the game;
*   Moving Quick Pits menu no longer results in a crash in some configurations;
*   Crashes with missing flame textures (with original flames) fixed;
*   Cosmic suspension: fix for some configurations of slider and rack joints misbehaving a bit;
*   An occasional crash with Sol weather style should be fixed;
*   Weather FX styles accessing output buffer with post-processing disabled shouldn't crash anymore;
*   Free camera alignment (photo app, Ctrl+F7) fixed;
*   Failure to initialize shared memory structures shouldn't lead to a crash anymore;
*   CSP car previews no longer activate reverse lights;
*   Pen support (for example, when using a Wacom tablet with Paint Shop app) improved;
*   An occasional crash caused by GIF/WEBP players should be fixed;
*   X360 Controller Debug is hidden if input method is not gamepad;
*   Time Attack mode crashes on unsupported tracks are cleaner;
*   Malformed TCP and UDP packets now fail with a corresponding message;
*   Audio with blown tyres fixed;
*   `mph` units are written properly;
*   Photo app: `Align` button fixed;
*   Failing to apply TrackIR CSP tweaks is fixed;
*   `Vote to kick` from driver's context menu no longer toggles the mute status;
*   Small fixes for the timezone sanity check;
*   Planet trajectories fixed;
*   Closing apps from context menu is saved properly;
*   Better handling of Assetto Corsa running out of memory;
*   Car Debug app: wheel torque is fixed (front torques were shown as rear, and vice versa);
*   Windscreen rain dirt chances increased a bit, especially on older cars (adjustable in car configs as `[RAIN_FX] WINDSCREEN_DIRT_CHANCE`);
*   A crash with `DI_…` or others CSP digital instruments extension, assigned to a non-text node, is fixed;
*   New `__EXT_LOOK_AXIS_LEFT` and `__EXT_LOOK_AXIS_RIGHT` axes for looking around;
*   New `[NODE_ADJUSTMENT] SHIFT_POSITION=X, Y, Z` just in case;
*   New `[CUSTOM_PHYSICS] DISABLE_ANY_EXTRAPOLATION=1` for exceptional cases (pretty much only for `altonline` to do its own extrapolation);
*   `FUEL_CONSUMPTION_…` car instrument inputs are fixed;
*   Controller inputs `LIGHT_EXTRA_G`…`LIGHT_EXTRA_T` and `DRL` are available to cars without extended physics too;
*   `LUT` of extra car animations fixed;
*   Car navigators save the state of satellite switch;
*   Script-driven car flames fixed, and the `FLAT_SHIFT_MASK` value is loaded correctly;
*   Inverted `TESSELLATION_FACTOR` should still work, using smaller value for distant geometry, and larger value for geometry nearby;
*   Malformed `WAV` values in `surfaces.ini` no longer crash the game during loading;
*   Track conditions: `INPUT_CHANGE_DELAY` and `BOUND_TO_SPECTATORS` are fixed;
*   Fix for missing textures with KN5 track asset streaming;
*   Lua scripts in other threads shouldn't crash Lua Debug app anymore;
*   Lua shaders: defines of 4D vectors fixed;
*   New `ac.onCarAIToggle()` event;
*   Other car events updated: pass `nil` as car index from car scripts to listen to events for the target car;
*   New `ac.SimState.lastFinalCameraPosition` field storing final camera position in the previous frame;
*   New `[TWEAKS] SPAWN_SET` parameter for New Mode scripts;
*   `ui.setScrollX()` / `ui.setScrollY()` respect `relative` with `smooth=false`;
*   `physics.setAISpline()` returns `false` if file is missing;
*   `ac.getSetupTabs()` failing to refresh data in some cases fixed;
*   Toggling `ac.disableLowSpeedFFBReduction()` in FFB scripts is working correctly;
*   Scene API: new `:applyBendingShader()`;
*   `ac.SceneReference:getChildrenCount()` sometimes returning insane values fixed;
*   Broken `ac.SceneReference:countMatches()` deprecated, replaced with `:countUnion()` and `:countIntersection()`;
*   Broken `ac.SceneReference:makeSubtractionWith()` deprecated, replaced with `:makeDifferenceWith()`;
*   Walking Out mode and `physics.setUserControlledCar()` are more compatible with some car physics scripts;
*   `ac.onLapCompleted()`: callback arguments `cuts` and `valid` are fixed;
*   CSP OpenXR implementation is better compatible with different runtimes;
*   Splashscreen: fallback image can be found with a relative path as well;
*   `ac.suspensionJointConfigure()` returns `true` if it finds a joint;
*   Docs for `ac.allowCarDRS()` of car physics scripts fixed;
*   Fixes for car physics scripts overriding wheel rotation;
*   `chat.extras.shareCarSetup()` fixed;
*   The `quat.new()` function referenced in the docs is no longer missing;
*   LuaSteam: `screenshots` and `music` modules fixed;
*   A few smaller fixes;
