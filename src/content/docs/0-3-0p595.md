# Changelog

## New features, options and improvements

*   Neural Rendering:
    *   Now works without upscalers;
    *   Compatible with HDR output;
    *   Settings moved to a separate section (use in-game app to move NR before upscalers);
    *   Move visual tweaks in in-game app, including multiple passes and extended boundaries;
    *   Accumulation screenshots improved, now NR applies once at the end instead (optional, enabled by default, can be changed in screenshots settings);
*   A bug causing issues with NoHesi servers fixed, CSP is better at syncing features list;
*   Motion blur shader updated to improve visuals and address a few issues;
*   BC7 background compression shouldn't cause any freezes anymore;
*   Upscaler crashes with misconfigured video settings (there is never a need to set MIP LOD bias below -5) fixed;
*   View & Video settings: glare slider goes all the way to 7 (highest quality);
*   Upscalers: option to adjust YEBIS glare to compensate for the lower scale and prevent excessive flickering;
*   New pixel density upscaler: Snapdragon GSR1 (so good and fast it's enabled by default);
*   Performance report includes the details about late frames;
*   A small regression in textures loading leading to extra aliasing at distance fixed;
*   Triple screen: temporal upscaling is working with module disabled, or with `fit resized splits properly` disabled;
*   Render Stats: freezes profiler updated, now tracks running script, keeps 25 slowest frames;
*   Async KN5 loading from Lua is more reliable;
*   Custom TrackIR implementation with a couple of small fixes, enabled by default, with a variant adjusting scale to ensure the proper match;
*   Neck FX is compatible with Track IR camera movement;
*   New `[DATA] DOOR_ANIMATION_CLOSE_SKIP` parameter for skipping a bit of door animation when closing;
*   Snapdragon GSR1 as pixel density upscaler is compatible with HDR output;
*   A bit of shine for grass at grazing angles with LCS;
*   Long speculars of SSLR are compatible with LCS;
*   Disabled smoke (all the smoke) no longer leads to a crash with rain;
*   `shared/sim/weather`: new `.rainMmPerHourToIntensity()` and `.rainIntensityToMmPerHour()` (rain intensity will be reworked next though, so do not rely on this one);
*   Oculus mode is enabled automatically if Assetto Corsa is launched from Oculus runtime (enabled by default);
*   VR controllers work when clicking buttons on the results screen;
