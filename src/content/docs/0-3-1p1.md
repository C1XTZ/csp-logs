# Changelog

## New features, options and improvements

## Fixes

*   Various font rendering glitches fixed;
*   Windscreen reflections no longer crash when the scene changes live;
*   Some unusual showrooms or tracks shouldn't crash AC anymore;
*   Tyres without Tyres FX no longer look overly bright in the rain;
*   A few other stability improvements;
*   Audio:
    *   `Alter wind audio` option rewritten, now only applies the fix to the cars with the original malfunctioning audio sample;
    *   Audio for the focused cars (wind and such) plays even if they're far away (for example, in replays);
    *   Bonnet and bumper cameras with interior audio are no longer extra loud;
*   Marble particles:
    *   Now use the new tyre state estimation, so they can work online as well;
    *   Size adjusted;
    *   A bit more jumpy and dynamic, with reduced drag, increased forces, and a chance to bounce up when pushed too much;
*   Upscalers:
    *   DLSS updated to 310.9.16;
    *   Temporal upscalers (DLSS, FSR2, XeSS): option for foveated upscaling (using SGSR2 for the outer regions);
    *   Neural Rendering: preset option (working with the new DLL);
    *   Neural Rendering: foveated rendering (reduce NR resolution towards the edges);
*   CSP trees:
    *   A few major bugs causing horrible performance issues fixed, plus a few extra optimizations;
    *   Trunk width value used for billboards fixed;
    *   Billboards of wide trees are now drawn correctly;
    *   Shading with LCS fixed: trees are no longer two and a half times brighter than they should be;
    *   Optional depth prepass that might help with performance (disabled by default);
    *   New `Better shadows for CSP trees` option using 3D models for shadows of nearby trees (for now, disabled by default);
    *   New `[LEAVES] COLOR_WEIGHTS` parameter to tweak the automatic mask (multipliers for R and B; defaults are 0.9 and 1. For yellow leaves, use 0.6, 1.5, or just use the `SEASON_AUTUMN_…` parameter when configuring the trees);
    *   New `[LEAVES] LEAVES_ARE_NOT_BARK` parameter for trees: set it to 1, and all the meshes that are not explicitly bark will be treated as leaves (careful if your leaf textures include sticks and such);
*   Miscellaneous:
    *   New experiment (disabled by default) averaging some of the car state values across elapsed physics frames instead of using the latest ones;
    *   New experimental visual car damage, disabled by default (for now, it doesn't work in replays, or for remote cars online);
    *   Long-lasting smoke and dust: a few fixes, now compatible with LCS;
    *   New warning about apps that hide the main car and cause rendering glitches;
    *   Thresholds for performance warnings raised (now, an app has to stall the actual driving experience for at least 100 ms, and other parts for at least 500 ms, or 1500 ms during the first 10 seconds of a session, to get a warning);
*   Configs:
    *   New `[AUDIO] PREFER_ORIGINAL_LOGIC` option for cars restoring most of the original audio logic and disabling alterations such as accounting for wind, or using actual braking intensity (enabled by default for VRC and URD cars, please DM me if I should enable it for your cars as well);
*   Content shaders:
    *   `smCarPaint` shaders: old flakes are a bit more pronounced with LCS;
    *   New car paint flakes updated: defaults improved, new `FlakesMask` parameter, by default, they only apply if the original materials had flakes as well;
    *   `fuPBR_multilayer` shaders are no longer pixelated at 10+ km from the scene origin;
