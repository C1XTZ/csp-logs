# Changelog

## New features, options and improvements

*   Crashes when changing camera with rain active fixed;
*   Crashes when preparing flags on some tracks fixed;
*   YouTube integration fixed;
*   `PUSH_TO_PASS/ACTIVATION_POS=0` in `engine.ini` no longer leads to a crash;
*   Small Tweaks: option to apply Neural Rendering to CSP car previews;
*   Windscreen raindrops looking weird with mods that wrongly disable backface culling for windscreen meshes fixes;
*   Objects Inspector shows materials with double-sided culling properly;
*   Physically simulated flags look correct with gamma color space;
*   AIs no longer go to pits with fuel rate at 0%;
*   Checks for simulated track flags are a bit looser, allowing for some slightly sagged flags to pass the test;
*   Screen rain drops work even if they're disabled for one of the cases (previously, because of a bug, everything had to be enabled);
