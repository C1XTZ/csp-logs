# Changelog

## Fixes

*   Rendering should be more stable, fixing some GPU crashes;
*   Window positioning for covering multiple monitors improved, better handles cases with an extra monitor above, misaligned monitors, etc;
*   Advanced scene chunkenizator no longer messes up rendering order across different KN5s, shouldn't break culling of dynamic entities;
*   Rim-ground contacts exclude walls;
*   Moving the mouse pointer with controller buttons or arrows works in the results menu;
*   Lollipop guy's animation fixed;
*   Distant car lights glare fixed, now a lot more selective in its choice of lights to attach to;
*   Tree swaying in wind fixed (regression somewhere around 0.3.0-preview358) and improved a bit;
*   Audio of exploding tyres no longer plays when a car is focused for the first time;
*   New vintage DDS texture loader fixed;
*   Race score used for CSP leaderboards and such no longer updates its inner track position state while the car is in pits;
*   Accumulation screenshots getting artifacts with YEBIS DOF fixed;
*   Critical DLSS init failures should be caught instead of crashing AC at launch;
*   A rare crash with single-triangle track physics meshes fixed;
*   Skidmarks no longer spawn if contact point is far from the ground plane; the ones from collisions properly stop based on surface type;
*   Car swaps no longer crash the game when loading a car that has been loaded before, or with windscreen reflections;
*   Windscreen FX can handle car swaps;
*   Track grooves fading in without a dynamic track surface fixed;
*   Logitech G27 lights extension no longer misreads RPM thresholds;
*   Track timezones parsing is more robust;
*   A bunch of fixes for the built-in PP filter editor;
*   INI parser misbehaving with single quotes and $ variables in some cases fixed;
*   Filling in missing F6 car cameras fixed;
*   Joy-Con support fixed;
*   Small fixes for changing control settings live, more logging;
*   VR:
    *   SPS: overly eager culling in the left eye fixed;
    *   Tree dithering in VR without VRS fixed;
    *   OpenXR: stage tracking space by default, option to restore recentre from the previous session (enabled by default);
*   AI:
    *   AIs consider fuel consumption rate when refueling and planning laps;
    *   Damaged AIs do not teleport to pits until fully stopped;
    *   Alternative AI updated, now with an option for getting back to the race and better pit parking, and an option to disable extra assists;
*   New menu:
    *   Support for custom number of Quick Setup menu presets;
    *   Max tyre temperatures are shown properly;
*   CSP flames:
    *   Most flame types on modern cars are no longer continuous;
    *   Linking to audio updated to react to peaks alone;
    *   Blue flames with LCS are dimmer;
*   CSP smoke:
    *   An option to use new spawn logic (for now, disabled by default);
    *   Movement and shading adjusted;
    *   Improved smoke-vs-car collisions;
    *   Stationary overheated tyres can emit smoke as well;
    *   Screen smoke no longer gets drawn at the wrong times if smoke is downscaled;
    *   TAA no longer leads to smoke artifacts around fast moving cars;
*   Rain FX:
    *   Wiper trails on exterior windscreens are optimized and improved;
    *   Some artifacts with puddles and dynamic rain line, especially on Linux, fixed;
    *   Tyres drying once the rain stops fixed;
*   Miscellaneous:
    *   New Track/Miscellaneous option to use cloth simulation for flags (disabled by default for now), with updated shading as well;
    *   `Monitor connected devices` option now looks for the IDs only, with an extra option to look for the names as well;
    *   Extra FX effects initialize a bit faster;
    *   TAA is a lot less ghosty (and a bit more flickery, but the old super-smooth approach caused a lot of issues);
    *   Some error messages are a bit more informative, especially the out-of-memory one if it's been caused by a lack of virtual memory;
    *   Extra canvases and OBS views (in high quality or above) include dynamic light shadows;
    *   Distant cars now also get reduced VAO when flipped, and can flash;
    *   DLSS: option to set custom quality;
    *   On crashes, CSP will try to stop FFB;
    *   New fields for `ndSlip` in `acpmf_physics` at offset 0x250;

## Config

*   Car configs:
    *   New flakes for metallic car paints (at the moment, should be available for the Kunos Audi S1, more configs are coming soon);
    *   `BIND_TO_LOWBEAM` for extra lights fixed;
    *   New options for `PARTICLES_FX_EXHAUST_FLAMES` sections: `COOLDOWN_TIME_MS`, `COOLDOWN_TIME_DISCHARGE_MS`, `COOLDOWN_TIME_SCRIPT_MS`;
    *   Tyres FX: parameter `DAMAGE_GRAIN_GAIN` is used properly;
*   Track configs:
    *   New `[TEXTURE_SIZE_LIMITS] WORLD_DETAIL_0 = tex_mask?.dds:256, …` option to limit the resolution of different textures for different world detail settings;
    *   Default `[WEATHER_FX] SKY_BELOW_HORIZON` value changed from 1 to 0.3, to help tracks with holes;
    *   Track conditions: delay on change is working properly, flashing works even without noise;
    *   `Material_PBR_Multilayer` no longer wrongly selects parallax shader;

## Lua

*   Lua API:
    *   `table.isArray()` fixed and optimized, no longer returns `true` for some weird tables, or tables starting with 0;
    *   `string.urlParse():getSearchParam()` for value-less parameters fixed;
    *   `stringify()` supports tables with keys of reserved Lua words, or tables starting with 0 index;
    *   `stringify.register()` called before `stringify()` no longer raises an error;
    *   `os.parseDate()` returns `nil` on error, instead of 0;
    *   `io.checksumSHA256()` no longer fails with empty files;
    *   `table.build()` fixed, `table.sum()` can handle callbacks returning `false`;
    *   New `:angle2()` and `math.angle2()` to replace old broken version, which are now deprecated and hidden;
    *   New `vec3:setCrossNormalized2()` having its arguments the right way around, `:setCrossNormalized()` is deprecated and hidden;
    *   `math.seededRandom()` fixed;
    *   `vec2/3/4:copyTo()` actually returns self;
    *   `rgb/rgbm:normalize()` returns self, as documented;
    *   `mat4x4:transform()/mat4x4:transformTo()` fixed, respect the `.w` component;
    *   `quat.new(vec4/quat)` fixed;
    *   `quat:table()`, previously only mentioned in docs, added;
    *   `rgbm:vec3()` and `rgbm.new(hsv)` fixed;
    *   `ac.lapTimeToString()`: docs fixed, case with overflow produces `99:99.999`, as documented;
    *   `os.dateGlobal()` is no longer limited to 80 characters;
    *   `io.arePathsEqual()` fixed;
    *   `ac.INIConfig.cspModule(ac.CSPModuleID.VRTweaks)` returns SPS state in `[SINGLE_PASS_STEREO]` section, fixing some issues with Pure;
    *   New `require('shared/utils/osutils').isHDREnabled()` to check if HDR is enabled in Windows settings;
    *   `luasteam` library fixed, no longer tries to load the GNS DLL for no good reason;
    *   Chase camera settings can be edited live, or with `ac.applyLiveConfigEdit()`;
    *   `render.PositioningHelper()` fixed (includes apps depending on it, such as AI Spline Editor);
    *   Binding Lua audio events to scene nodes now properly handles velocity;
    *   `string.replace()` no longer explodes with an empty needle;
    *   `ac.getPitstopSpinners()` properly updates when the selected preset changes;
    *   `ac.overrideRacingFlag()` shouldn't get stuck when released;
    *   `ac.getCarColliders()` fixed (it had an issue if called repeatedly with different `actualColliders` params);
    *   `render.debugLine()`: parameter for dashed line;
    *   `ac.SceneReference:setMaterialProperty()` no longer caches previous values, should solve a few issues;
    *   `ac.StateCar.drivenInRace` ignores lap progress if car is in pitlane, or the race hasn't started yet;
    *   New `physics.overrideAIRequestedFuel()`;
    *   `ac.setWiperMode()` can be used in replays as well, overriding stored state;
    *   `:applyShaderReplacementsAsync()` preloads shaders in the background;
*   Lua:
    *   LuaJIT interpreter updated: a few fixes, a bunch of new syntax extensions (the VS Code extension has been updated as well);
    *   Arrow syntax for captureless functions now reuses functions, improving performance but leading to shared identity, so be careful (more details in `lua-sdk/readme.txt`);
    *   Doing `local mmin = math.min` to speed things up at the start of the file is no longer necessary;
    *   Lua preprocessor fixed (a couple of edge cases were causing some major issues before);
