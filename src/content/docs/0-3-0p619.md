# Changelog

## New features, options and improvements

*   VR:
    *   Regular upscalers (FSR1, SGSR1, NIS) are working with SPS;
    *   Render targets are always cleared (fixing some problems with some tracks);
    *   Loading screen shows the reason VR failed to initialize;
    *   OpenVR: option to show race details during loading;
    *   VR mirroring stabilization resets on start or sudden changes, works better with corner masking;
    *   Small fixes;
*   Variable Rate Shading for VR:
    *   SPS is no longer required, settings moved to a separate section (to keep old presets working, SPS settings will be reset instead);
    *   Areas automatically align with view direction;
    *   In case automatic alignment fails, options to tweak things are available, with an optional debug overlay too;
    *   VRS no longer applies to HUD;
*   Rain FX:
    *   Rain physics tuned, should be manageable now;
    *   Rain drops are more compatible with TAA, more intense for heavier rain;
    *   More rain hits for overly intense rains;
    *   Rain on glossy surfaces (such as car paint) adjusted, shading improved;
    *   Wipers audio is quieter (I should redo those samples later for sure);
    *   New `[RAIN_FX] IDEAL_LINE_RAIN_FACTOR` for track configs (set to 0 to stop rain physics from taking ideal line and its corresponding rubbering into account);
*   Default Weather FX style:
    *   Rain audio fixed, boosted for higher intensities;
    *   Ambient shadows are a bit less dark;
    *   Some of the more extreme weathers are tuned to be less extreme;
*   Upscalers and Neural Rendering:
    *   DLSS updated to 310.9.1;
    *   New XeSS 3.0.2 upscaler (works with GPUs other than Intel Arc);
    *   New FSR3/4 upscaler using DirectX 12 API;
*   Neural Rendering:
    *   Crashes when resizing AC fixed;
    *   Enabling the effect mid-session adds the tweaking app;
    *   New `loop` slider in `Go beyond` settings;
    *   `Allow to load unofficial DLLs` fixed, list of known unofficial DLLs extended;

## Fixes

*   Crash with any smoke disabled fixed (should actually be fixed this time);
*   Lap counter at the top showing one fewer lap than it should fixed;
*   Python apps trying to create textures of 0 pixels in size no longer cause Assetto Corsa to crash;
*   `FREQUENT_TRACK_CHANGES` feature is working with tracks with layouts;
*   TAA: shadows shouldn't leave trails as much;
*   Small fixes for screenshots, new `Output a frame every accumulation step` option just in case (disabled by default);
*   Settings for mouse steering scripts are loading correctly;
*   CSP can handle strange track models (such as `vhe_interlagos` with meshes with 489888 vertices and 210 triangles wasting 64 MB of disk and memory space);
*   Crash with Unbound app and other scripts using `ac.overrideCarControls()` should be fixed;
*   Shader replacements with `CULL_MODE = DOUBLESIDED` are applying correctly now;
*   Missing or damaged `pitcrewtyre.ini` no longer crashes Assetto Corsa;
*   Crashes related to some of taskbar icon lifespan aspects fixed;
*   Burnable track geometry shouldn't lead to crashes;
*   Neck FX: fixes for the original (non-scripted) implementation;
*   Saving `car.ini` when adjusting first person camera works with `Use extended physics` CM tweak too;
*   Car swaps handle steering wheels in secondary LODs properly;
*   Revenant mode no longer activates extended physics;
*   DualSense haptic feedback:
    *   No longer messes up audio with some of the cars;
    *   Selects output device to match the gamepad (for setups with multiple DualSense gamepads);
*   Skidmarks:
    *   Tread textures fixed;
    *   `Save as OBJ` saves skidmarks on session exit, regardless of `Save between sessions` option;
*   Extended server configs:
    *   New `[CUSTOM_PHYSICS] NEW_MOTION_PREDICTION=1` parameter replacing physics extrapolation of remote cars with something a bit more advanced (new motion is applied automatically in altonline sessions, unless they opt out);
    *   New `[CUSTOM_PHYSICS] RAW_TIMESTAMPS=1` for servers with uneven packet rate;
    *   `[CUSTOM_PHYSICS] EXTRAPOLATE_STATE` removed;
*   Extended car physics:
    *   `[_EXTENSION] AWD2_INVERTED=1` should work now, making front axle the leading one (make sure to specify minimal CSP version for your cars as 4150 or newer);
    *   Use `[_EXTENSION] RIM_SPRING_RATE=0 RIM_DAMPING_RATE=0` to disable rim contacts entirely;
*   Troubleshooting-related:
    *   Crash reports include CSP log;
    *   Hardware details are logged at launch;
    *   Crash reports can be uploaded for further analysis;
*   Miscellaneous:
    *   GNS library (used for P2P connections without Steam servers) updated, now comes with proper ICE client instead of using WebRTC;
    *   A few improvements for P2P signalling, peers now should be able to find each other even if LAN doesn't have internet access;
    *   AI flood: distance tweaks are visible in settings again;
    *   Press Ctrl+Alt+Shift+Win+F10 to get a report, instead of F12, which is now taken by Copilot;
    *   CSP bindings to shift gears, or shift to a neutral gear, adjusted, now work as long as they're pressed, not just for the first frame;
    *   `Extrapolate car state properly` experiment promoted to done (I finally figured out why remote cars were shaking);

## Lua

*   New `io.available()` function;
*   New `dynamic::efx::depth`, `dynamic::efx::…` textures are available to other scripts too (although, without triple resolution);
*   New functions `physics.exportRacingLineAsync()` and `physics.importRacingLineAsync()` for syncing rain state online;
*   Web browser is available again for scripts without I/O access;
*   Pinned graphics for `ac.debug()` of car physics scripts no longer duplicate on data changes;
*   Small fixes for docs;
*   Lua Debug app: script ordering is fixed;
