# Changelog

## New features, options and improvements

*   Live settings reload fixed;
*   A few broken shaders (such as `stPerPixelMultiMap_specular`) are fixed (recent regression);
*   No more sparks when cars scrape against gravel (another recent regression);
*   New experimental rims blur in Cars/Visual;
*   CSP marbles are affected by wind, forces slightly reduced;
*   New car damage: breaking glass and rear mirrors;
*   Smart Mirrors: option to always show side virtual mirrors;
