# Changelog

## New features, options and improvements

*   VR:
    *   OpenXR integration, with optional tweaks (separate HUD layer, hand and eye tracking, passthrough);
    *   Outer VRS radius is ignored completely, so rendering no longer stops in outer regions after the `Align with eyes` option;
    *   Custom VRS rate and area are configurable;
    *   New VRS supersampling option;
*   Miscellaneous:
    *   Smoke with LCS looks better;
    *   Photo app: option to always show the grid, plus golden-ratio grids;
    *   New DDS loader for vintage textures (palette, L8, LA88, and so on), a bit faster;
    *   Default Weather FX: distant fog in intense rain has been tuned;
    *   FSR 3/4 updated, now using the FSR loader DLL to improve compatibility;
*   No more crashes:
    *   Caused by malformed vector values in AC configs (for example, a missing second number for `CHROMATIC_ABERRATION/LATERAL_DISPERSION`);
    *   On Wine, when converting malformed strings between UTF-8 and UTF-16;
    *   With driver models that lack `DRIVER:RIG_Clave_R` and such;
    *   If there isn't enough memory for refracting headlights (they are skipped instead);
    *   When handling Python errors;
    *   With Extra FX at very low resolutions;
    *   When a car physics script blocks everything, for example to show a message;
    *   Caused by the new media tracking;
    *   If an XeSS or FSR DLL fails to load;
    *   When creating a ghost for a car without wheels;
    *   Caused by scripts passing large amounts of data to and from workers;
    *   If the `[LIGHTING]` section in `race.ini` is missing;
    *   Caused by the loading profiler with Python apps;
    *   When AI cars try to use malformed splines;
    *   If car data curves are missing or empty;
    *   If reading or writing a file fails mid-operation;
    *   When saving setups shared in chat;
    *   When trying to load damaged encrypted models;
    *   If sides of triple screen have a width of zero, Weather FX style uses cloud masks, and an extra car camera activates (all at once);
*   Rain FX:
    *   Rain drops and windscreen drops: amounts adjusted;
    *   A few small tweaks for rain drops visuals;
    *   Windscreen banners no longer look messy in the rain when Extra FX is off;

## Fixes

*   Amount of dust particles on collisions is tuned down to avoid performance issues;
*   `fuPBR` materials fixed, now with a new `PerceptualRoughness` option (if materials look dim, set it to 1);
*   Neural Rendering works with old upscalers with TAA and Extra FX disabled;
*   Failure to create a buffer for a screenshot, or a similar failure, no longer stops Neural Rendering for the entire session;
*   Remote cars jitter with the original extrapolation fixed;
*   `Compress generated missing MIPs` option improved, now with caching and support for textures of unusual sizes;
*   Translucent windscreen banners and other translucent materials are compatible with Single Pass Stereo;
*   Xbox impulse triggers no longer fire while the race is paused;
*   `Final lap tweak` fixed: the white flag no longer stays up for the whole race;
*   The green flag goes away once the leader has finished their laps, or once time runs out in timed sessions;
*   The default rule for guessing rear-view cameras changed from `below the driver's eyes` to `5 cm or more below the driver's eyes`, fixing issues with some mods;
*   Changing light direction in the replay UI works with Weather FX;
*   CSP brake discs no longer mishandle small visual tweaks;
*   The new PNG loader shouldn't use too much memory during the loading process;
*   Bodywork audio position is a bit more distinct;
*   Disabling track-camera wobble no longer breaks cameras that follow splines;
*   A few textures that failed to load properly are fixed;
*   New menu: the slipstream slider no longer misbehaves when the initial slipstream amount is not 100%;
*   Extended car physics:
    *   `TYPE_HINT=WET` is an alias for rain tyres (the previously expected value is `RAIN`);
    *   `[SPEED_LIMITER]` units fixed, now actually km/h;
    *   Add `[_EXTENSION] GENERATE_EXTRA_TYRES=0` to `tyres.ini` to disallow CSP from generating any additional tyres;
*   Configs:
    *   `MAX_DISTANCE` for track cameras in CSP configs, so cameras keep working far from the player (default is 400 m);
    *   Hidden `[FMOD]` section in `general.ini` for advanced tinkering;

## Lua

*   New `ac.overrideTyreIgnitionPoint()`;
*   New `os.listAudioDevicesAsync()` and `os.openAudioOutput()`;
*   `ui.endTextureShade()` throws on mismatched call instead of taking Assetto Corsa down;
*   New functions for loading screen scripts: `loading.hold()`, `loading.ready()`, `loading.proceed()`;
*   Malformed Lua docs fixed;
