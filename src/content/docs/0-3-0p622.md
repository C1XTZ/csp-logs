# Changelog

## New features, options and improvements

*   Windscreen reflections no longer crash the game when swapping cars in some cases;
*   Fixed compatibility with AC Pro;
*   Visual issues on the `pk_gunma_cycle_sports_center` track fixed with a built-in config patch;
*   Using simplified YEBIS post-processing on 1×1 textures no longer leads to a crash;
*   Rain physics malfunctioning on some tracks with certain configurations fixed;
*   New main menu no longer ignores the mouse in compact mode when shifted up;
*   Custom collision settings for walls should work again;
*   More informative error messages;
*   Manually triggered crashes (without Assetto Corsa getting stuck) are no longer uploaded;
*   Ideal line messing up rain physics on some tracks fixed;
*   P2P 1v1 mode failing to load on some PCs fixed;
*   Changing material textures via Lua no longer crashes the game (especially on No Hesi servers);
*   Loading models in the background, especially for scripts, is less crash-prone now;
*   A rare deadlock caused by wheels-vs-cars collisions should be fixed;
*   Multithreaded loading occasionally crashing, especially with static reflections, fixed;
*   Finishing a VR session in Oculus mode should work better;
*   Shared AC physics state is more compatible with rain tyres and such;
*   Rain FX no longer crashes on cars without `COCKPIT_HR`;
*   A few smaller fixes;
